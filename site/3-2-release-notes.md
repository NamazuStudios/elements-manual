<h1>3.2 Release Notes</h1>

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading" id="h-elements-3-2-release-notes">Elements 3.2 Release Notes</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>We’re excited to announce the release of <strong>Elements 3.2</strong>, delivering major upgrades in usability, developer tooling, and platform integration. Here’s what’s new:</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":4} -->
<h4 class="wp-block-heading" id="h-gui-configuration-editor">GUI Configuration Editor</h4>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>A new <strong>visual configuration editor</strong> is now built in, allowing you to manage all application settings through an intuitive interface. We’ve also resolved several configuration-related bugs to streamline setup and deployment.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":4} -->
<h4 class="wp-block-heading" id="h-openapi-swagger-code-generator">OpenAPI/Swagger Code Generator</h4>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Elements now supports an <strong>OAS3-compliant code generator</strong>, enabling automatic generation of client and server code from your API definitions. This improves type safety and speeds up integration across services.</p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":4} -->
<h4 class="wp-block-heading" id="h-editor-plugin-available-on-the-unity-asset-store">Editor Plugin Available on the Unity Asset Store</h4>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>The new <strong>Unity3D editor plugin</strong> is now live on the <strong>Unity Asset Store</strong>. It automatically generates all client-side code within the Unity Editor, enabling your game to call any Elements API with zero manual setup.</p>
<!-- /wp:paragraph -->
