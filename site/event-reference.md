<h1>Event Reference</h1>

<!-- wp:paragraph -->
<p>This page catalogs every event published by Namazu Elements' built-in services and DAOs, so you can consume it from your own Element with <code>@ElementEventConsumer(...)</code> or publish it yourself with <code>@ElementEventProducer</code>. For how the event system works, including code samples and how to discover events at runtime from the CMS, see <a href="events">Events</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Each row names the event by the interface constant that declares it (linking to that interface's Javadoc, which opens in a new window), the literal event name string, the payload arguments delivered to your consumer, and the earliest release the event appeared in. Javadoc links throughout this page are pinned to the <a href="https://apidocs.namazustudios.com/elements/index.html" target="_blank" rel="noopener">published API docs</a> for <code>3.9.0-rc-10</code>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>DAO-level lifecycle events follow the two-variant pattern described in <a href="events">Events</a>: for every payload below, a transactional variant of the same event also exists, carrying the same arguments plus a trailing <code>Transaction</code>, and fires inside the write itself rather than after it commits. Where a row's payload already lists <code>Transaction</code>, that is the event's only form.</p>
<!-- /wp:paragraph -->
<!-- wp:paragraph -->
<p>The "Since" column gives the earliest tagged release in which the event appeared. Most of the catalog is new in 3.9, when create/update/delete events were extended to nearly every DAO (see the <a href="3-9-release-notes">3.9 release notes</a>).</p>
<!-- /wp:paragraph -->
