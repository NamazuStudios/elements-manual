<h6 class="wp-block-heading" id="h-restful-apis-for-elements-3-0-x">RESTful APIs for Elements 3.0.x</h6>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Your instance of Elements provides its own built-in documentation generated by <a href="https://swagger.io/">Swagger</a> and will always report the most accurate version based on what you are currently running. This is available to view at /doc/swagger. When running Community Edition locally, you may always find the latest at the following URL <a href="http://localhost:8080/doc/swagger/">http://localhost:8080/doc/swagger/</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>For the Elements Core APIs, enter <a href="http://localhost:8080/api/rest/openapi.json">http://localhost:8080/api/rest/openapi.json</a> into the explore bar.</p>
<!-- /wp:paragraph -->
