# Namazu Elements Manual

This repository is the **source of truth** for the Namazu Elements manual. It contains the raw Markdown source for every page published at [namazustudios.com/docs](https://namazustudios.com/docs/), and is kept as a **bi-directional mirror** of that site:

- Edits made on the docs site are synced here (via BetterDocs) so this repo always reflects the live manual.
- Edits made here — through pull requests — are synced back and published to the live site.

In other words, contributing here is the correct way to fix, improve, or extend the official Namazu Elements documentation.

## Repository layout

All manual content lives under site, with one Markdown file per documentation page (e.g. `elements-in-five-minutes-or-less.md`, `data-models.md`, `leaderboards.md`, release notes, troubleshooting guides, and more).

## Contributing

Found a typo, an outdated instruction, a broken link, or a gap in the docs? Please contribute:

1. **Open an issue** describing what's wrong or missing, or
2. **Open a pull request** with the fix directly against the relevant file(s) in `site/`.

Corrections, clarifications, and new content are all welcome. Once merged, changes flow through to the published manual at [namazustudios.com/docs](https://namazustudios.com/docs/).
